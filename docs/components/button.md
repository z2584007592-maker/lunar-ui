# Button 按钮

常用的操作按钮，API 风格参考 Element Plus。

## 基础用法

<lunar-button>Default</lunar-button>
<lunar-button type="primary">Primary</lunar-button>
<lunar-button type="success">Success</lunar-button>
<lunar-button type="warning">Warning</lunar-button>
<lunar-button type="danger">Danger</lunar-button>

## 禁用与加载

<lunar-button disabled>Disabled</lunar-button>
<lunar-button type="primary" loading>Loading</lunar-button>

## Props

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| type | 按钮类型 | `default / primary / success / warning / danger` | `default` |
| size | 按钮尺寸 | `large / default / small` | `default` |
| plain | 是否朴素按钮 | `boolean` | `false` |
| round | 是否圆角按钮 | `boolean` | `false` |
| loading | 是否加载中 | `boolean` | `false` |
| disabled | 是否禁用 | `boolean` | `false` |
